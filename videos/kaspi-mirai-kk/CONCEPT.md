# CONCEPT — kaspi-mirai-kk

## Формат
Рилс 9:16, 1440×2560, 60 fps.

## Стиль: свой — «ЭКРАН»
Готовые стили и паттерны репозитория владелец использовать не разрешил. Стиль собирается с нуля
из `studio/src/kit` под этот ролик.

**Механика.** В кадре — один телефон с чистым экраном, перерисованным начисто по фотографиям владельца:
никаких рук, комнаты, бликов и пальцев. Экран крупный, занимает основную часть кадра; над ним —
номер и название шага на казахском. Место нажатия показывает метка касания: круг расходится там, куда
жмёт палец, и экран переходит на следующий. Поля формы заполняются на глазах — текст набирается по буквам,
как при вводе с клавиатуры.

**Почему так.** Ролик обучающий: родителю нужно узнать свой экран один в один и повторить. Любая
декоративная графика поверх интерфейса мешает узнаванию, поэтому украшений нет — есть экран, подпись шага
и метка нажатия.

**Чем отличается от прошлых роликов студии.** Здесь нет карточки спикера, камеры по холсту и стеклянных
предметов. Главный и единственный объект кадра — интерфейс приложения.

**Шаги (по материалам владельца):**

1. Главная Kaspi.kz → «Платежи».
2. Платежи → поиск.
3. Поиск → «Mirai School» на Аскарова.
4. Форма: ФИО и ИИН учащегося, класс.
5. Проверка периода и суммы → «К оплате».

**Данные на экранах — выдуманные.** Настоящие ИИН и ФИО с фотографий владельца в ролик не переносятся.

- Сумма к оплате на последнем экране (ожидает ответа).
